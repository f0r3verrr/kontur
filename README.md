# Контур · Kontur

Локальный пульт для Windows 10 и 11. Переключает звук между двумя выбранными выходами и показывает заряд периферии.

## Как пользоваться

Распакуйте портативный архив целиком и запустите `Kontur.exe`. Если прежняя версия уже работает, сначала закройте её через **Exit** в трее. Сборка использует прежние настройки и историю батарей.

- Кнопка **Настроить выходы** назначает реальные устройства слотам **Колонки** и **Наушники**. Если Windows однозначно определяет пару, Контур выбирает её при первом запуске.
- **Добавить устройство** помещает выход Windows в правую колонку под **Наушниками**. Там его можно выбрать напрямую. В окне **Настроить выходы** можно переименовать устройство в Контуре или удалить дополнительный выход. Левый клик по значку рядом с часами перебирает доступные выходы по кругу. Приложения, привязанные к конкретному устройству, продолжают использовать выход из своих настроек.
- В разделе **Зарядка** выбор устройства меняет график под списком. Доступны последние 24 часа и семь дней. Заряд также виден на панели задач. По кабелю Attack Shark X6 показывает `USB` и последний известный заряд, если в истории есть замер.
- Закрытие главного окна оставляет приложение в трее. Команда **Exit** завершает его. **Start with Windows** запускает приложение в трее после входа в систему.

История хранится локально в профиле Windows. Переключатель реагирует на события Windows, заряд проверяется примерно раз в минуту и при изменении USB-подключений.

## Голосовые команды

Контур также поддерживает голос [Piper Irina](https://huggingface.co/rhasspy/piper-voices/tree/v1.0.0/ru/ru_RU/irina/medium). Чтобы попробовать его, скачайте модель и её файл `.onnx.json` в `voice/piper`. Контур выбирает Irina, когда видит оба файла, иначе использует Denis.

Откройте раздел **Голос** в главном окне и включите **Голосовые команды**. Кнопка **Все команды** открывает справочник по функциям, включая сохранённые сценарии. Произнесите «Контур, переключи звук на колонки» или «Контур, переключи звук на наушники». Можно сказать «Контур» отдельно и дать команду в течение семи секунд. Когда Контур ждёт команду, чуть ниже центра экрана появляется индикатор микрофона.

«Контур, включи Яндекс Музыку» открывает установленное приложение. «Контур, включи Яндекс Музыку и волну» запускает «Мою волну». «Контур, выключи музыку» ставит Яндекс Музыку на паузу. Для воспроизведения нужен аккаунт с доступом к сервису.

- «Следующий трек», «Предыдущая песня» и «Что сейчас играет?» управляют настольной Яндекс Музыкой. «Поставь лайк» и «Убери лайк» управляют отметкой текущего трека.
- «Сделай Discord потише» снижает громкость его сеансов в микшере Windows на 10 процентных пунктов. Можно также сказать «Сделай голосовой чат потише». «Музыку на 100 процентов» выставляет уровень Яндекс Музыки в микшере Windows. «Сделай музыку потише» уменьшает уровень на 10 процентных пунктов. Для регулировки у приложения должен быть сеанс в микшере.
- «Выключи музыку через 20 минут» ставит таймер на паузу воспроизведения. Остаток времени и отмена доступны через меню в трее. Также можно сказать «Сними таймер». Таймер действует, пока работает Контур.
- В разделе **Голос → Мои сценарии** можно сохранить до пяти фраз на русском. Например, для «Контур, играем» выберите наушники, паузу Яндекс Музыки и запуск Discord.

Контур проверяет обновления на GitHub при запуске. Кнопка **Проверить обновления** запускает проверку вручную. Для автоматической установки релиз должен содержать `Kontur-update-win-x64.exe`. Перед заменой проверяются версия и SHA-256 файла.

После успешной голосовой команды Контур озвучивает сохранённую фразу локальным нейросетевым голосом Piper. В карточке **Голосовой ответ** можно заменить фразу или выключить озвучивание. Громкость меняется в **Звук → Настроить выходы → Громкость ответа Контура** и применяется только к озвучке. Во время ответа распознавание приостанавливается. Piper запускается только для синтеза, а последний готовый ответ хранится в памяти до выключения голосового режима.

Включённый режим использует микрофон Windows по умолчанию. До активации распознаватель ищет слово «Контур» и пропускает тихие фрагменты. После него на семь секунд создаётся распознаватель команд. Аудио и текст обрабатываются локально, в память попадает только короткий буфер для активации. Записей на диске и отправки в сеть нет. Выключение режима освобождает микрофон и модель.

Если в разделе «Голос» написано «Голосовой пакет не найден», распакуйте архив с голосом целиком. Для уже установленного Контура достаточно закрыть его и скопировать папку `voice` рядом с `Kontur.exe`.

Для сборки без голосового пакета положите рядом с `Kontur.exe` папку `voice`. В неё нужны четыре DLL из [Vosk 0.3.45 для Windows x64](https://pypi.org/project/vosk/0.3.45/#files), а [модель vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models) нужно распаковать в `voice/model` так, чтобы существовал файл `voice/model/am/final.mdl`. Портативный архив с голосом уже содержит эти файлы.

Для нейросетевых ответов дополнительно нужны [Piper для Windows](https://github.com/rhasspy/piper/releases/tag/2023.11.14-2) в `voice/piper` и [совместимая версия модели Denis](https://huggingface.co/rhasspy/piper-voices/tree/e7229f7d33a10e145e109b886d661984201ac3c4/ru/ru_RU/denis/medium) рядом с `piper.exe`. Архив с голосом уже содержит их. В сборке без Piper озвучку выполняет Windows.

## Сборка Windows

Из оболочки MinGW-w64 запустите `make` или `build.bat` с `g++` и `windres` в PATH. Результат — `Kontur.exe`. Команда `Kontur.exe --list` выводит обнаруженные батареи.

## Структура приложения

- `src/kontur.cpp` запускает приложение, управляет окном и передаёт события модулям.
- В `src/panel.cpp` общая оболочка строит боковую навигацию из списка `kModules`. Каждый раздел отрисовывает содержимое своей функцией.
- `src/audio.cpp` отвечает за аудиовыходы, их имена и порядок переключения. `src/battery_monitor.cpp` запускает опрос батарей, а `src/history.cpp` обслуживает историю. Драйверы устройств находятся в `src/drivers`.
- `src/voice.cpp` управляет микрофоном, активацией и распознаванием команд. После распознавания контур передаёт команду звуковому модулю.
