# Контур · Kontur

Локальный пульт для Windows 10 и 11. Переключает звук между двумя выбранными выходами и показывает заряд периферии.

## Как пользоваться

Распакуйте портативный архив целиком и запустите `WirelessBattery.exe`. Если прежняя версия уже работает, сначала закройте её через **Exit** в трее. Сборка использует прежние настройки и историю батарей.

- Кнопка **Настроить выходы** назначает реальные устройства слотам **Колонки** и **Наушники**. Если Windows однозначно определяет пару, Контур выбирает её при первом запуске.
- **Добавить устройство** включает дополнительный выход Windows в переключатель. Через **Другие выходы** можно выбрать его напрямую. Левый клик по значку рядом с часами перебирает доступные выходы по кругу. Приложения, привязанные к конкретному устройству, продолжают использовать выход из своих настроек.
- В разделе **Зарядка** выбор устройства меняет график под списком. Доступны последние 24 часа и семь дней. Заряд также виден на панели задач. По кабелю Attack Shark X6 показывает `USB` и последний известный заряд, если в истории есть замер.
- Закрытие главного окна оставляет приложение в трее. Команда **Exit** завершает его. **Start with Windows** запускает приложение в трее после входа в систему.

История хранится локально в профиле Windows. Переключатель реагирует на события Windows, заряд проверяется примерно раз в минуту и при изменении USB-подключений.

## Сборка Windows

Из оболочки MinGW-w64 запустите `make` или `build.bat` с `g++` и `windres` в PATH. Результат — `WirelessBattery.exe`. Команда `WirelessBattery.exe --list` выводит обнаруженные батареи.

## Основа и лицензия

Контур создан на базе [Wireless Device Battery Monitor](https://github.com/krisgfx9/Wireless-Device-Battery-Monitor). В [исходном README](WIRELESSBATTERY.md) сохранены список поддерживаемых устройств и сведения о протоколах. Интерфейс Контура и переключатель звука предназначены для Windows.
