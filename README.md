# Контур · Kontur

Локальный пульт для Windows 10 и 11. Переключает звук между двумя выбранными выходами и показывает заряд периферии.

## Как пользоваться

Распакуйте портативный архив целиком и запустите `Kontur.exe`. Если прежняя версия уже работает, сначала закройте её через **Exit** в трее. Сборка использует прежние настройки и историю батарей.

- Кнопка **Настроить выходы** назначает реальные устройства слотам **Колонки** и **Наушники**. Если Windows однозначно определяет пару, Контур выбирает её при первом запуске.
- **Добавить устройство** помещает выход Windows в правую колонку под **Наушниками**. Там его можно выбрать напрямую. В окне **Настроить выходы** можно переименовать устройство в Контуре или удалить дополнительный выход. Левый клик по значку рядом с часами перебирает доступные выходы по кругу. Приложения, привязанные к конкретному устройству, продолжают использовать выход из своих настроек.
- В разделе **Зарядка** выбор устройства меняет график под списком. Доступны последние 24 часа и семь дней. Заряд также виден на панели задач. По кабелю Attack Shark X6 показывает `USB` и последний известный заряд, если в истории есть замер.
- Закрытие главного окна оставляет приложение в трее. Команда **Exit** завершает его. **Start with Windows** запускает приложение в трее после входа в систему.

История хранится локально в профиле Windows. Переключатель реагирует на события Windows, заряд проверяется примерно раз в минуту и при изменении USB-подключений.

## Голосовые команды

В меню значка рядом с часами включите **Голосовые команды · Контур**. Произнесите «Контур, переключи звук на колонки» или «Контур, переключи звук на наушники». Можно сказать «Контур» отдельно и дать команду в течение пяти секунд.

Включённый режим использует микрофон Windows по умолчанию. До активации распознаватель ищет слово «Контур» и пропускает тихие фрагменты. После него на пять секунд создаётся распознаватель команд. Аудио и текст обрабатываются локально, в память попадает только короткий буфер для активации. Записей на диске и отправки в сеть нет. Выключение режима освобождает микрофон и модель.

Для сборки без голосового пакета положите рядом с `Kontur.exe` папку `voice`. В неё нужны четыре DLL из [Vosk 0.3.45 для Windows x64](https://pypi.org/project/vosk/0.3.45/#files), а [модель vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models) нужно распаковать в `voice/model` так, чтобы существовал файл `voice/model/am/final.mdl`. Портативный архив с голосом уже содержит эти файлы.

## Сборка Windows

Из оболочки MinGW-w64 запустите `make` или `build.bat` с `g++` и `windres` в PATH. Результат — `Kontur.exe`. Команда `Kontur.exe --list` выводит обнаруженные батареи.

## Структура приложения

- `src/kontur.cpp` запускает приложение, управляет окном и передаёт события модулям.
- В `src/panel.cpp` общая оболочка строит боковую навигацию из списка `kModules`. Каждый раздел отрисовывает содержимое своей функцией.
- `src/audio.cpp` отвечает за аудиовыходы, их имена и порядок переключения. `src/battery_monitor.cpp` запускает опрос батарей, а `src/history.cpp` обслуживает историю. Драйверы устройств находятся в `src/drivers`.
- `src/voice.cpp` управляет микрофоном, активацией и распознаванием команд. После распознавания контур передаёт команду звуковому модулю.
